Калькулятор выражений

О программе

Программа реализована на графическом интерфейсе QT. Калькулятор имеет возможность расчитать результат введеного выражения.

Пользователь имеет возможность задать x, для этого нужно в поле ввода ввести чему он будет равен.

Он автоматически будет подставлен в введеное выражение в основном поле ввода.

В программе реализована кнопка "Draw" (построение графика), также есть поля для ввода, где пользователю предложено

задать область координат, в которых будет выводится график.

Реализованы кнопка "Кредит" (Кредитный калькулятор). Появляется новое окно для расчёта ежемесячного платежа по

заданным параметрам.

Кредит (СreditCalculator) – нахождение ежемесячного платежа по заданной сумме и сроку кредита.

Установка

Требуется библиотека QT

Система сборки qmake

Чтобы установить калькулятор воспользуетесь командой make install. Эта команда установит программу в папку

home/SmartCalc

make производит установку и тестирование функций.

Удаление

Удалить пользовательскую программу, вы можете использовав команду make uninstall.

make clean - очистит все сгенерированныt файлs
